# BiblioPerso 5.0.1 — dernières étapes

Le projet Firebase `biblioperso-3ffe9` est déjà intégré à l'application.

## 1. Publier les règles Firestore
Dans Firebase :
1. Firestore
2. Onglet Règles
3. Remplacer tout le contenu par celui du fichier `firestore.rules`
4. Cliquer sur Publier

## 2. Autoriser GitHub Pages
Dans Firebase :
1. Authentication
2. Paramètres
3. Domaines autorisés
4. Ajouter `sanssouci70.github.io`

## 3. Mettre cette version sur GitHub Pages
Remplacer les fichiers actuels du dépôt par ceux de ce dossier.

## 4. Créer le compte de synchronisation
Sur le PC :
1. Ouvrir BiblioPerso
2. Menu > Synchronisation PC / iPhone
3. Saisir une adresse e-mail et un mot de passe
4. Cliquer sur Créer le compte

Si le Cloud est vide, la bibliothèque locale du PC est envoyée automatiquement.

## 5. Connecter l'iPhone
1. Fermer puis rouvrir BiblioPerso
2. Menu > Synchronisation PC / iPhone
3. Utiliser la même adresse e-mail et le même mot de passe
